# بیلیارد سه‌بعدی ۸ بال — 🎱

یک بازی **بیلیارد سه‌بعدی کامل** که کل آن در **یک فایل HTML** جا می‌گیرد:
`pool-3d.html` (بدون هیچ فایل جانبی، بدون اینترنت، آمادهٔ اجرا با دوبار کلیک).

## شروع سریع
```bash
# فقط فایل را در مرورگر باز کنید
xdg-open pool-3d.html       # لینوکس
open pool-3d.html           # مک
start pool-3d.html          # ویندوز
```

## امکانات
- **گرافیک سه‌بعدی**: میز حرفه‌ای با بالشتک‌های شیب‌دار، ریل چوبی، جیب‌های چرمی با حلقهٔ برنجی،
  پارچهٔ بافت‌دار، توپ‌های براق با بافت شماره‌دار، نورپردازی نمایشگاهی، سایه‌های نرم و نقشهٔ محیطی.
- **فیزیک واقعی**: برخورد کشسان توپ‌توپ، اصطکاک غلتشی، ضریب بازگشت بالشتک، جیب‌های شش‌گانه،
  شبیه‌سازی با گام ثابت ۲۴۰ هرتز.
- **کنترل حرفه‌ای**: خط نشانهٔ کامل با پیش‌بینی مسیر توپ هدف (ghost ball)، **قدرت با کشیدن و رها کردن**،
  **چرخش توپ** (جلو/عقب/جانبی) با دایرهٔ اسپین، دوربین مداری کامل + نمای نشانه‌گیری + نمای بالا.
- **قوانین ۸ بال**: شکستن، میز باز، تعیین گروه، نوبت ادامه‌دار، خطاها (نخوردن به توپ، توپ اشتباه،
  توپ سفید در جیب)، «توپ در دست»، برد/باخت با توپ ۸.
- **حریف هوش مصنوعی** سه‌سطحی: انتخاب توپ و جیب، بررسی مسیر باز، زاویهٔ برش، قدرت مناسب،
  جای‌گذاری توپ سفید و ضربهٔ امنیتی.
- **صدا**: تمام افکت‌ها با Web Audio ساخته می‌شوند (برخورد، بالشتک، افتادن در جیب، ضربهٔ چوب) — بدون فایل صوتی.
- **رابط کاربری فارسی و راست‌به‌چپ**، سازگار با موبایل و لمسی.

## کلیدها
| کلید | کار |
|---|---|
| حرکت ماوس | چرخاندن نشانه |
| کشیدن ماوس + رها کردن | ضربه (قدرت = میزان کشیدن) |
| کلیک راست/وسط یا `Shift`+کشیدن | چرخاندن دوربین |
| اسکرول / چرخ | زوم |
| `Space` | ضربه با قدرت اسلایدر |
| `↑` `↓` | کم/زیاد کردن قدرت |
| `←` `→` | چرخاندن دقیق نشانه |
| `V` | نمای نشانه‌گیری |
| `C` | نمای بالای میز |
| `W A S D` | جابه‌جایی مرکز دوربین |
| `M` | صدا |
| `R` | شروع دوباره |
| `Esc` | توقف |

## ساختار پروژه
فایل نهایی از این قطعات ساخته می‌شود:

```
src/shell.html      اسکلت و رابط کاربری
src/style.css       طراحی رابط
src/sim.js          موتور مستقل بازی: فیزیک، جیب‌ها، قوانین ۸ بال، حریف AI (قابل اجرا در Node)
src/game.js         رندرر، صحنه، نور، بافت‌ها
src/table.js        ساخت میز و جیب‌ها
src/balls.js        توپ‌ها، چوب، نشانه‌گیری
src/audio.js        افکت‌های صوتی
src/ui.js           جریان بازی، دوربین، کنترل‌ها
src/main.js         حلقهٔ اصلی
vendor/three.min.js کتابخانهٔ three.js r128 (MIT)
build.py            همه را در pool-3d.html ادغام می‌کند
```

بازسازی فایل نهایی:
```bash
python3 build.py
```

## تست
```bash
node test/harness.js
```
هارنس، فایل نهایی را با jsdom و یک WebGL ساختگی اجرا می‌کند و کل چرخهٔ بازی
(شکستن، نوبت‌های متقابل، جای‌گذاری توپ، برد با توپ ۸، حالت تمرین، اسلایدر قدرت، منو) را بررسی می‌کند.
برای اجرا به `jsdom` نیاز دارد (`npm i jsdom`).
