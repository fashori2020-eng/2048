# 2048 — بازی تک‌فایلی

بازی کلاسیک ۲۰۴۸ در یک فایل HTML، بدون هیچ وابستگی.

- اجرا: فایل `index.html` را در مرورگر باز کنید (یا با `python3 -m http.server 8080`).
- کنترل: کلیدهای جهت‌دار / WASD، سوایپ روی موبایل، `Z` بازگشت، `R` بازی جدید.
- امتیاز، رکورد و وضعیت بازی در `localStorage` ذخیره می‌شود.
