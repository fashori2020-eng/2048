# بیلیارد سه‌بعدی حرفه‌ای (8-Ball Pool 3D)

یک بازی کامل بیلیارد هشت‌توپ، سه‌بعدی، **در یک فایل `index.html`** و کاملاً آفلاین.
کافی است `index.html` را در هر مرورگر مدرنی (Chrome / Firefox / Safari / Edge) باز کنید —
هیچ کتابخانه، فونت، صدا یا تصویری از اینترنت بارگذاری نمی‌شود.

> کتابخانهٔ Three.js r147 (حدود ۶۰۰ کیلوبایت) به صورت درونی (inline) در همان فایل قرار گرفته است.

## امکانات

- **گرافیک سه‌بعدی واقعی**: میز چوبی با باندهای شیب‌دار، نمد بافت‌دار، ۶ پاکت با دهانه و حلقه،
  نشانه‌های الماسی روی باند، پایه‌های میز، کف اتاق، نورپردازی استودیویی، سایهٔ نرم،
  بازتاب محیطی (PMREM) و متریال براق Clearcoat روی توپ‌ها.
- **۱۶ توپ شماره‌دار**: توپ‌های ساده، راه‌راه، توپ ۸ و توپ سفید با بافت ساخته‌شده در لحظه؛
  چرخش توپ‌ها هنگام غلتیدن، سایهٔ تماسی و انیمیشن افتادن داخل پاکت.
- **فیزیک اختصاصی**: شبیه‌سازی ۲۴۰ قدم بر ثانیه، برخورد الاستیک توپ‌ها، اصطکاک غلتشی،
  واکنش باندها با دهانهٔ پاکت‌ها، جذب توپ توسط پاکت، جلوگیری از نفوذ/گیرکردن توپ‌ها.
- **نشانه‌گیری حرفه‌ای**: خط چین مسیر، توپ شبح محل برخورد، بردار حرکت توپ هدف،
  مسیر انحراف توپ سفید و پیش‌بینی انعکاس از باند.
- **چوب بیلیارد سه‌بعدی** با عقب کشیدن متناسب با قدرت و انیمیشن ضربه.
- **قوانین ۸ توپ دو نفره**: تعیین گروه (ساده/راه‌راه)، ادامهٔ نوبت، خطاها
  (اسکرچ، بدون برخورد، برخورد اول اشتباه، توپ ۸ زودهنگام، نرسیدن به باند)،
  «توپ در دست»، اعلام برنده و جدول امتیازات زنده.
- **صدا**: افکت‌های سنتزشده با Web Audio (برخورد، باند، ضربه، پاکت) + دکمهٔ قطع صدا.
- **کنترل کامل دوربین**: چرخش با راست-درگ، زوم با اسکرول، نمای بالا، دکمه‌های لمسی،
  و تنظیم خودکار کادر برای نمایشگرهای عمودی/مربعی.
- رابط کاربری کاملاً **فارسی و راست به چپ**، واکنش‌گرا برای موبایل و دسکتاپ.

## کنترل‌ها

| عمل | روش |
| --- | --- |
| جهت ضربه | حرکت ماوس روی میز (خط راهنما) یا کلیدهای `←` `→` |
| قدرت ضربه | نگه داشتن کلیک چپ و کشیدن به عقب، سپس رها کردن |
| شلیک سریع | دکمهٔ «ضربه بزن» یا `Enter` (قدرت از اسلایدر) |
| شارژ با کیبورد | نگه داشتن `Space` و رها کردن |
| چرخش دوربین | راست-درگ روی میز / دکمه‌های `↶ ↷ ▲ ▼` |
| زوم | اسکرول ماوس / دکمه‌های `＋ －` |
| نمای بالا | دکمهٔ «نمای بالا» یا `T` |
| شروع مجدد | دکمهٔ «شروع مجدد» یا `R` |
| صدا | دکمهٔ 🔊 یا `M` |
| توپ در دست | بعد از خطا، کلیک روی نقطهٔ دلخواه میز |

## ساختار فنی

`index.html` شامل سه بخش است:
1. Three.js درونی (UMD، بدون نیاز به CDN).
2. `Phys`: موتور فیزیک خالص و مستقل از DOM (قابل تست در Node).
3. `game`: صحنهٔ سه‌بعدی، بافت‌های رویه‌ای (Procedural Canvases)، صدا، ورودی،
   ماشین حالت بازی و رابط کاربری.

برای اجرا از طریق سرور محلی (اختیاری):

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```
